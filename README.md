# FWG Website Theme
This theme was made originally for the Furry Writer's Guild. I have been volunteering for the Furry Writers' Guild (FWG) since 2021, having been brought on to help support their [current website](https://furrywritersguild.com) on Wordpress and to help design their prospective new website on the [Ghost](https://ghost.org) blogging platform using the CSS framework [Bulma](https://bulma.io).

## To Use this theme:
The easiest way to use the theme is to create a website on [ghost.org](https://ghost.org) and upload the theme zip file to the website:
1. Download this repo
2. Create a website on [ghost.org](https://ghost.org) or [Host Ghost locally](https://docs.ghost.org/install)
3. In the Admin panel (yoursitename.com/ghost), navigate to **Settings > Themes**
4. Click **Change Theme**
5. Click **Upload Theme**
6. Choose the `Leggy.zip` file found within this repo

Many links in the navigation require pages to be set up with the specific URL.
